# PhotoMind

本地离线桌面应用，用于照片管理与思维导图式联想整理。完全离线运行，**不修改、不移动、不删除用户原图**（只记录路径与生成缩略图缓存）。

## 功能特性

- **相册首页**：以方形相册卡片网格展示，导入文件夹后照片自动进入「未分类」相册；每个自定义分类也是一个相册卡片（一张照片可属于多个分类）。
- **分类管理**：右下角「+」新建分类（名称 + 颜色）；右键分类相册卡片可「重命名相册 / 删除相册」。
- **照片查看器**：大图四周留白显示、滚轮缩放、拖拽平移、双击复位、上一张/下一张（按钮 + 键盘 ← →）、显示文件名与序号、给照片多选分类；**分类后自动无缝切到下一张**。
- **联想画布**：无限画布，从左侧照片库把照片拖入生成图片节点；节点可移动/缩放/删除；节点之间连线、连线标签、删除连线；自动保存，重启后节点/连线/标签/位置全部恢复。
- **性能**：缩略图缓存（sharp 生成）、图片懒加载、缩略图虚拟列表；首页布局 4/6/8 列可切换并记住。

## 技术栈

Electron · React 19 · TypeScript · Vite（electron-vite）· SQLite（Node 内置 `node:sqlite`）· React Flow（@xyflow/react）· Zustand · Tailwind CSS · sharp

## 环境要求

- Windows 10/11（64 位）
- 开发构建需 Node.js ≥ 22.12（本项目用 Node 22.5+ 内置的 `node:sqlite`，无需 C++ 编译）与 npm

## 安装步骤

### 方式一：使用安装包（推荐）

1. 运行 `PhotoMind Setup 0.1.0.exe`。
2. 选择安装目录（或保持默认）。
3. 安装完成后，从桌面/开始菜单启动 PhotoMind。

### 方式二：免安装便携版

解压 `win-unpacked` 文件夹，双击其中的 `PhotoMind.exe` 即可运行，无需安装。

> 首次启动若被 Windows SmartScreen 拦截，点「更多信息 → 仍要运行」。本应用为本地单机程序，无任何联网上传行为。

### 方式三：源码运行

```powershell
npm install
npm run dev
```

若 Electron 二进制下载缓慢或失败，项目已内置 `.npmrc` 走国内镜像。

## 使用说明

1. **导入照片**：首页点「导入文件夹」，选择一个照片目录（递归扫描 jpg/jpeg/png/webp/gif/bmp）。导入的照片会进入「未分类」相册。
2. **新建分类**：首页右下角点「+」，输入名称并选择颜色。
3. **给照片分类**：进入相册 → 点照片打开查看器 → 点右上「分类」勾选/取消分类。分类后会自动切换到下一张继续浏览。
4. **管理分类相册**：右键分类相册卡片，可「重命名相册」或「删除相册」（删除只移除分类，不删照片）。
5. **联想画布**：顶部切到「联想画布」，从左侧照片库拖照片进画布；从节点右侧圆点拖线到另一节点左侧圆点建立连线；点连线中间标签编辑文字。

## 数据存储位置

所有数据统一存储在**程序所在目录下的 `data/` 子目录**（开发模式为项目根目录 `data/`，不写入 C 盘 AppData）：

```
data/
├── photomind.db     # SQLite 数据库（照片、分类、画布等）
├── thumbnails/      # 缩略图缓存
├── session/         # Electron/Chromium 缓存
├── logs/            # 日志
└── tmp/             # 临时文件
```

```powershell
npm run build:win
```

## 常见问题（FAQ）

**Q1：启动时提示 Windows 已保护你的电脑 / SmartScreen 拦截？**
点「更多信息 → 仍要运行」。原因是没有购买代码签名证书，属正常现象。

**Q2：安装 Electron 时下载失败/很慢？**
项目已配置国内镜像（`.npmrc`）。若仍失败，可手动设置：`npm config set electron_mirror https://npmmirror.com/mirrors/electron/`。

**Q3：照片显示为空白或缩略图打不开？**
可能原图被移动/删除或格式损坏。重新导入（或点「补录文件夹」）即可刷新；软件不会修改原图。

**Q4：重装或换电脑后数据还在吗？**
应用数据保存在 `data/photomind.db`，备份该目录即可迁移。导入目录后请勿移动被导入的原图文件夹。

**Q5：打包报 native 模块 / sharp 错误？**
确认 Node 版本满足要求，并确保网络可访问国内镜像。sharp 使用 N-API 预编译包，通常无需本地编译。

**Q6：导入大量照片卡顿？**
已内置缩略图缓存与虚拟列表；首次导入需生成缩略图，稍候即可。可在首页右下角切换 4/6/8 列。

## 验收测试

1. 导入含子文件夹的多格式照片目录 → 首页出现「未分类」相册卡片（方形、封面 + 数量）。
2. 点相册 → 点照片进查看器：滚轮缩放、拖拽平移、双击复位、← → 切换。
3. 查看器内点「分类」加入某分类 → 自动切到下一张；返回首页可见该分类相册。
4. 右键分类相册可重命名/删除；右下角「+」可新建分类。
5. 重启软件，照片/分类/画布数据均保留。
6. 全程不修改、不删除本地原图。
